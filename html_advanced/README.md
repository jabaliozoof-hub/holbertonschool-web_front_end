# HTML Advanced - Techium Project

This directory is dedicated to mastering advanced HTML5 concepts, structural layouts, and clean coding standards as part of Holberton School.

## Learning Objectives
- Understanding advanced HTML5 structural guidelines.
- Structuring a complete website (`Techium`) using semantic tags (`<header>`, `<main>`, `<footer>`, `<article>`, `<nav>`, etc.).
- Implementing lists, data tables, and media embeds (`<img>`, `<iframe>`, etc.).
- Writing code that adheres strictly to W3C validation standards.

## Tasks Progress
- **Task 0:** Create the first basic webpage (`0-index.html`) with proper `lang="en"` and `dir="ltr"` attributes.
